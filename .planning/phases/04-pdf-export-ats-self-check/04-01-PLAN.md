|----------|-------------|

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-04-01 | Tampering | render.py interpolations | high | mitigate | html.escape(quote=True) on EVERY interpolated string; gate's accent/mojibake checks catch corrupted extractions; test_render_html pins the escape behavior |
| T-04-SC | Tampering | uv add playwright / pypdf | high | mitigate | Task 0 blocking human-verify legitimacy checkpoint (pypi.org pages confirmed before install); versions pinned exactly (playwright==1.62.0, pypdf>=6.19.0) |

| T-04-06 | Denial of Service | per-request Chromium launch | low | accept | Localhost single-user tool; ~0.9s launch per export is the documented cost (research A1); no reuse cache to avoid cross-thread sync-Playwright state bugs |
