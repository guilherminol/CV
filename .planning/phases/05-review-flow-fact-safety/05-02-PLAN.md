| Boundary | Description |
|----------|-------------|
| edited text → DOM render | User/LLM text re-renders in the card on every save/restore |
| edited text → export payload | Displayed state posts verbatim to /api/resume/exportar (Phase 4 contract) |
| session state lifetime | Versions/edits live in memory only — no persistence boundary exists |
