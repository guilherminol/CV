## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → /api/resume/regenerar | Untrusted JSON body (JD text, dica, submitted sections) crosses into Pydantic validation |
| user dica → LLM user message | Free-text hint crosses into the prompt as DATA |
| LLM output → response envelope | Model output crosses back to the client as section content |
| exception detail → log vs envelope | Raw error text must stay terminal-side |
