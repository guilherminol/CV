<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| .env secret → SDK client | API key crosses from local config into outbound HTTPS |
| Real untrusted LLM output → assertions | Live responses (not fakes) enter validation for the first time |
| Fixture texts → model context | Large pasted texts are still untrusted input (injection vector unchanged) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-09 | Information Disclosure | OPENROUTER_API_KEY in harness runs | high | mitigate | Key read only from gitignored .env via app/config.py; never printed in assertions, never written to runs.jsonl; test failures must not embed the key (assert on model/slug, not auth headers) |
| T-02-10 | DoS (wallet) | -m llm real spend | medium | mitigate | Spend bounded: 5 tests x LLM_MAX_ATTEMPTS x max_tokens from PromptSpec; marker excluded from every default run (addopts, proven in 02-01); skipif prevents confusing charged partial runs |
| T-02-11 | Repudiation | harness results | low | mitigate | Every real run leaves audit lines in runs.jsonl (stage/model/tokens/cost) — the log is the record of what was spent and why (D-13/D-14) |
| T-02-12 | Tampering | live LLM output | high | mitigate | Same gateway path as production: strict json_schema + require_parameters provider preference + Pydantic re-validation; invalid content retries then fails loudly — never passes to assertions as success |
</threat_model>
