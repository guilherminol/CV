## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| OpenRouter response → backend retry loop | Untrusted LLM output re-enters the model context as correction material |
| Backend → logs/runs.jsonl | Audit file that must stay secret-free and content-free |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-05 | Elevation | retry loop (injected assistant content) | medium | mitigate | Appended assistant content is schema-constrained data, never executed; loop bounded by LLM_MAX_ATTEMPTS=3 (D-04) — worst case is a loud LLMError |
| T-02-06 | DoS (wallet) | retry loop | high | mitigate | Hard retry cap from config; every attempt logged with cost (D-14) so runaway spend is auditable from runs.jsonl alone |
| T-02-07 | Information Disclosure | runs.jsonl per-attempt lines | high | mitigate | Lines carry tokens/cost/latency/status/error-summary only; validation-error raw detail goes to terminal (exc.raw), not the JSONL line; logs/ already gitignored (02-01) |
| T-02-08 | Tampering | KEYWORD_STRICT_SCHEMA drift | medium | mitigate | Drift-lock test (Task 1) fails CI if the wire schema and Pydantic model diverge — a drifted schema is how invalid content sneaks past validation |
</threat_model>
