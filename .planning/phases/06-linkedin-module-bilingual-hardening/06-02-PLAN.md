|----------|-------------|
| user → objetivo + dica fields | Free text crosses into prompt composition (prompt-injection DATA surface) |
| submitted secoes → regen merge | Client-submitted state re-enters the server (spoofing/tampering surface) |
| LLM → wire schemas | Generated content crosses strict validation — never trusted |
| API → browser | Envelopes must not leak raw internals |
